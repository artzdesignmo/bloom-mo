# Bloom Mo — Generative Botanical Studio

Every flower grown from code. Eight species, infinite unique blooms — no two alike.

🌸 **[Live demo](https://artzdesignmo.github.io/bloom-mo/)**

## What it does

- **8 species engines** — Rose, Cherry Blossom, Sunflower, Orchid, Lotus, Lavender, Tulip, Wild Daisy
- **Procedural generation** — petal count, shape, color, stem curve, leaf placement all randomized. Every bloom is unique.
- **Growth animation** — flowers sprout and unfurl in real time
- **Interactive garden** — click anywhere to plant, or grow a surprise bouquet
- **PNG export** — save your garden as an image
- **Bilingual** — EN / 繁中 toggle
- **100% in-browser** — vanilla HTML/CSS/JS, zero dependencies

## Tech

Canvas 2D procedural botany: bezier petal geometry, gradient shading, seeded random generation, growth-phase animation. No image assets — every petal is drawn in code.
